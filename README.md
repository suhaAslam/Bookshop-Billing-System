# Pahana Edu Bookshop Billing System

## Overview
A webapp billing system for Pahana Edu built with Java (JSP/Servlets), Tomcat server , and MySQL for the db. It has:
- User Login 
- Customer management: add , edit , delete , view
- Item management: add , edit , delete , view
- Bill calculation & viewing
- Help page
- used MVC for architectural pattern
- JUnit tests


##  Technologies used
- Java 
- JSP/Servlets 
-  Tomcat 9
- MySQL , JDBC
- HTML , CSS & javascript
- Maven 
- GitHub 
- JUnit (tests)


## Testing 
- junit 
- manual test cases 
- Tests are under src/test/java

- ```bash
   git clone https://github.com/suhaAslam/Bookshop-Billing-System.git
